# Sky Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw every catalog object with the approved icons, inside the app.

**Architecture:**
- `scripts/build-catalog.mjs` adds icon `figure`s and cluster `members` to the generated catalog.
- `src/components/sky-icons/` ports the approved sheet's drawing code to React, with theme tokens.

**Tech Stack:** React 19, Vitest (with `react-dom/server` for render tests), astronomy-engine.

**Spec:** `docs/superpowers/specs/2026-11-20-sky-icons-design.md`

## Global Constraints

- Match the approved sheet (`icons-v8.html`, from `scratchpad/icons.template.html`) shape for shape.
- Use theme tokens only, each with a red-light value.
- Site code style. The user commits.

## Review Focus

- **Every catalog object renders without throwing:** a loop render test (Task 3).
- **Red-light mode:** no hard-coded hex colors in the icon files; a grep test (Task 3).
- **Duplicate SVG ids** when the same icon appears twice: `useId` (Task 3).
- **The home door's monthly constellation:** it still finds its figure for every month in both hemispheres (Task 4).
